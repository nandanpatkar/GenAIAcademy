Introduction to Amazon Connect Agent Applications
Lesson objectives

In this lesson, you will:

Identify Amazon Connect agent applications and their core functionality.
Recognize the benefits of using Amazon Connect agent applications.

Lesson introduction

Contact center agents need access to relevant customer context to effectively handle contacts across different channels. Amazon Connect offers two web browser applications agents can use to address customers' inquiries: the Contact Control Panel (CCP) and the agent workspace. In this lesson, you will learn about the core functionality offered by these applications.

Amazon Connect agent applications

Contact Control Panel (CCP)

The CCP application allows agents to interact with customers. Within the CCP, agents can dial, consult, transfer or conference calls, handle or transfer chats, or handle offline tasks related to customers. 

To launch the CCP, agents use a browser bookmark or a desktop shortcut to a URL link provided by their contact center administrator. This allows them to work from home or from their organization’s office.

With the CCP, agents can take calls over an internet connection using any supported web browser and a USB headset. The Agent headset and workstation requirements for the CCP(opens in a new tab) link includes guidance on minimum and recommended agent equipment. Amazon Connect can also be configured to forward the audio portion of a call to agents' mobile devices or any phone number they own. In this configuration, agents must first log into the CCP using a supported browser and make themselves available to take calls.

Agent workspace

The agent workspace is a single, intuitive interface that provides agents with customer information and assisted guidance. The CCP widget is embedded in the agent workspace, giving agents access to all CCP features. With the agent workspace, agents handling interactions on any channel can see the customer data and context as soon as their interaction starts. Agents get real-time guidance and suggestions on the steps to follow to solve customer issues fast.

Benefits of agent applications

Scale operations while providing high quality voice

The CCP delivers high quality real-time web communication (WebRTC) audio and video over an internet connection. This helps organizations deliver excellent customer service without having agents tied to a traditional call center setup.

Built-in functionality

The Amazon Connect CCP is a single, intuitive communication interface for agents. Agents use the CCP to interact with customers. With the CPP, agents can receive voice calls, digital messages, and task interactions. Agents have the ability to transfer contact interactions to other agents, put contacts on hold, and perform other tasks. Expand the following categories to learn more about the built-in functionality of CCP.


Change agent status
–
In the built-in CCP, agents can select the status Available to handle contacts. This means inbound contacts can be routed to them. Agents can also select the Offline status. This means no contacts will route to them.



Companies can use custom statuses to have discrete reporting about the time agents spend offline. Examples of common statuses include: Break, Training, and Lunch. 



After Contact Work (ACW) is an agent status that is set when agents complete a necessary set of tasks after interacting with the customer. These tasks include updating the customer record, logging the reason for contact and outcome, updating colleagues, and scheduling follow-up actions. ACW varies across different customer queries and resolution requests. There is no predetermined duration of ACW. However, it is a metric that impacts average handle time (AHT) and hence, and must be closely tracked.



You can configure the CCP to automatically move an agent to an after contact work (ACW) state when a conversation between agent and customer ends. The ACW configuration value represents the number of seconds agents will not receive any new calls so they can complete the post call tasks. Once the configured ACW duration expired, CCP automatically goes back to Available, and the agents can receive new contacts. 



An ACW value of 0 means the agents have an indefinite amount of time to complete tasks. In this configuration, when agents finish their post contact updates, they must select the Close contact button to become Available for the next contact. Unlike other statuses, agents cannot choose the ACW status. Supervisors can use the Amazon Connect reporting functionality to identify how long an agent spent on ACW for a contact.



To find out more about the agent status options, refer to the About agent status(opens in a new tab) section of the Amazon Connect Administrator Guide.

Use Quick connects
–
Quick connects act like a speed dial for agents. With Quick connects, agents can transfer interactions to other agents, queues, or external numbers. They can also use Quick connects to make calls or transfer calls to external numbers. Quick connects must be configured before agents can see them in the CCP.

Amazon Connect CCP screenshot showing the Quick Connect list during an active call.

Work with Tasks
–
With Amazon Connect Tasks, organizations can prioritize, assign, and track user work items to completion. For example, using Tasks you can:

Follow-up on customer issues recorded in a customer relationship management (CRM) solution, such as Salesforce.
Follow-up with a customer through a call.
Complete actions in a business-specific system, such as processing a customer claim in an insurance application.
With Amazon Connect, organizations can expand the benefits of the skills based routing engine and reporting to users that are not directly handling customer interactions. Consider the following scenario: a contact center agent receives a customer request to deliver a brochure for a specific product. The agent creates a Task in the CCP for the mailing department. The customer information is automatically displayed to the mailing department user that picks up the request. Despite the fact that the mailing department user is not directly communicating with the customer, they can help solve a customer issue. Both the call and the Task are tracked in the same reporting system. The mailing department user does not require an Amazon Connect user license to access the Tasks functionality.

Additional CCP integration and customization options with Amazon Connect Streams

Amazon Connect provides organizations with the ability to customize their CCP. For example, they integrate the CCP with their customer system of record and other applications the agents use to effectively address customer inquiries.

Developers can integrate the CCP widget into existing CRM web pages or create their own interfaces for agent applications. To learn more, expand the following categories. 


Embed the built-in CCP widget
–
Using the Amazon Connect Streams API, developers can embed the CCP widget inside of the web based CRMs that agents use. With this integration approach, the agents get access to CCP contact and status controls within the same workspace where they access the customer data. An example of application that uses embedded CCP widget is the Amazon Connect CTI Adapter. For more details, refer to the Embed the CCP into Salesforce(opens in a new tab) documentation. The core functionality of the Amazon Connect CTI Adapter provides a WebRTC browser-based CCP within Salesforce.



You can find more details in the Embed a custom Contact Control Panel (CCP)(opens in a new tab) section of the Amazon Connect Administrator Guide. 


Use controls without the built-in CCP interface
–
Some organizations require simple call control, such as Answer, Hold, and Disconnect functionality. For these use cases, developers can use the Amazon Connect Streams API to provide call and agent status control, without displaying the CCP view. With this approach, a CRM page will only display an Answer, Hold, and Disconnect button for their phone controls, and not the full CCP interface.


Build a custom CCP interface
–
Developers can embed the standard built-in widget interface and benefit from the ability to change states, answer interactions, or transfer them via Quick connects. They can then add a customer data panel, a disposition code panel, or agent stats panel. An example of a custom customer data and disposition panel this can be seen in the following image.

Data

Customer profile data: The contact data is available and displayed as soon as an incoming contact is presented to the agent. For contacts successfully associated with a customer profile in the IVR, the Customer Profile view displays all the available contact information. Based on their configured permissions, agents can create, view, and update standard customer profile data, such as name, date of birth, phone numbers, or email addresses.

IVR data: With additional IVR flows configuration, agents can see contact related information collected during the IVR interaction. Some examples include: contact IVR menu selections or chatbot intents, or customer sentiment following a chatbot conversation. The contact data is delivered to the agent application through contact attributes(opens in a new tab). Data can be displayed in configurable views built as part of the agent experience flows.

Agent assist functions

The ease of access to customer data is only one of the agent assist functions available in the agent workspace.

Step-by-step guides: Similar to building a customer experience, flow designers can create workflows to improve agent experience by using Show view(opens in a new tab) flow blocks. The agent workspace displays dynamic views that suggest actions agents can take at any given moment during a customer interaction. Agent workflows may include: display of single page form or detailed step-by-step views and forms that give clear instructions on how to handle a particular use case. Another common example of step-by-step guidance is helping agents enter a disposition code at the end of the contact.

Responses, recommendations, and information links: With Amazon Q in Connect, agents can manually lookup information available in their organization's knowledge base repositories. Additionally, Amazon Q in Connect can identify intent from live calls or chat transcripts and automatically initiate a relevant search for the agents. Agents then benefit from a suggested response for the customer, a list of suggested actions, and links to the relevant information. 

Organizations can chose to enable the real-time contact center analytics functionality provided by Amazon Connect Contact Lens. When Contact Lens analytics are enabled, Amazon Q in Connect processes the voice transcription of the live conversation between the customer and the agent. It then automatically initiates a relevant search in the knowledge base. Contact Lens real-time analytics are not required for chat or other digital messaging interactions. Amazon Q in Connect uses the live chat transcript to perform the same actions as for voice call transcripts.

Lesson introduction

When using Amazon Connect agent applications, it is important for organizations to consider security permissions as they develop and implement security policies. It is also helpful to verify service quotas and understand the limits and request increases to adjustable quotas. 

The Amazon Connect flexible pricing model allows organizations to scale their number of users at no additional cost. When enabling and configuring Amazon Connect agent workspace functionality, we recommend checking the pricing of each service to avoid unexpected costs for your organization.

In this lesson, you will review all these considerations. 

Security

(opens in a new tab)(opens in a new tab)Amazon Connect administrators manage users and assign appropriate permissions so they can access the features they need. Most companies have rules that grant different level of access to Amazon Connect users based on their roles.

When logging into an agent application, Amazon Connect agents are first identified and authenticated by using their organization's identity provider. Once authenticated, Amazon Connect authorizes access to functionality within the contact center by using security profiles. 

Security profiles provide secure role-based access to specific areas of the Amazon Connect application. A security profile consists of a set of permissions allowing users to view, modify, and delete resources, or to simply use features and functionality. One of the required agent security permissions is access to the CCP. Agents need this security permission to handle incoming contacts in the CCP or agent workspace. For more information about security profiles, see best practices for security profiles(opens in a new tab) in the Administrator Guide.

Service quotas

When planning user access to agent applications, administrators must also take into consideration service quotas for all the services agents need to use. Service quotas are the maximum values for the resources and operations in your Amazon Web Services (AWS) account. In addition to Amazon Connect quotas, such as Number of users per instance, administrators must also consider adjusting quotas for Amazon Connect Contact Lens usage. Automatic detection of contact intent and Amazon Q in Connect recommendations requires Contact Lens real-time analysis to be enabled. Administrators must consider adjusting Concurrent real-time calls with analytics and Concurrent chat analytics jobs quotas according to the service usage.(opens in a new tab)(opens in a new tab)

For integrations with third party applications added to the agent workspace, administrators should also verify App Integrations quotas and API throttling quotas.

Service quotas details for Amazon Connect are available in the Amazon Connect service quotas(opens in a new tab) section in the Administrator Guide.

Pricing

The cost of agent interactions in the CCP and agent workspace depends on the features a company enables. Planning workflows carefully and calculating the cost of each functionality in a workflow helps companies achieve optimal results at greatest cost-efficiency. 

To learn about Amazon Connect’s current pricing for the functionality you use in the agent workspace, review the Amazon Connect pricing(opens in a new tab) web page.

Lesson 6 of 9
Summary
Course summary

In this course, you learned about Amazon Connect agent applications. Amazon Connect offers agents two out-of-the-box applications: Contact Control panel and agent workspace. You explored the benefits of agent applications and learned about the agent experience using each application. Take a moment to review these key concepts in the course summary before taking the course assessment. 

Benefits
Scale operations while providing high quality voice: The CCP delivers high quality real-time web communication (WebRTC) audio and video over an internet connection. This helps organizations deliver excellent customer service without having agents tied to a traditional call center setup.
Simplify agent operations with a unified agent experience: By integrating with internal and external applications, the agent workspace empowers agents to quickly resolve complex issues. Agents benefit from a unified view of customer information, AI powered recommendations, and step-by-step guidance.
Reduce handle time with contextual agent guidance: The agent workspace can automatically identify customer issues and recommend appropriate steps to solve them. It uses data available for the current contact to dynamically adapt and provide agent guidance.

CCP
The CCP is an application that helps agents interact with customers. Within the CCP, agents can dial, consult, transfer or conference calls, handle or transfer chats, or handle offline tasks related to customers.



Agents use a browser bookmark or a desktop shortcut to a URL link provided by their contact center administrator. This allows agents to work from home or from their organization's office.



The built-in CCP features include:

The ability to handle interactions across any of the channels configured in the contact center.
The ability to select an Available status from the agent status drop-down list.
Configuration settings such as log out, speaker, headphone, and microphone settings. Other settings include redirecting the audio to a mobile device or desk phone and language settings.
Quick Connects: Pre-configured destination numbers that agents can use to dial or transfer interactions.
Number Pad: Agents can manually enter 10-digit external phone numbers. They can also send DTMF digits when interacting with an IVR system.
CCP integration and customization options:

Large organizations often customize their CCP by integrating it with their customer system of record and other applications used by agents to address customer inquiries effectively.
Developers can embed the built-in CCP widget into existing CRM web pages. By embedding the CCP widget, agents can access contact and status controls within the same workspace where they access customer data.

For organizations that require simple call control functionality (Answer, Hold, and Disconnect), developers can use the Amazon Connect Streams API to provide these controls without displaying the full CCP interface.

Screenshot Amazon Connect CCP displaying a connected call.
Agent Workspace
Agent workspace integrates multiple Amazon Connect features into a single application, including:

Contact Control Panel for interacting with customer contacts.
Customer Profiles for viewing customer information.
Cases for creating, updating, and resolving customer issues.
Amazon Q in Connect for receiving recommendations and suggestions.
Step-by-step guides for speeding up issue resolution.
Customer Profiles allows agents to view contact history and customer information from multiple data sources during the interaction.



Cases enable agents to create, track, and resolve customer issues that require multiple interactions across teams. It provides a unified view of each customer's issue, steps taken, and the outcome.



Amazon Q in Connect provides real-time agent assistance powered by generative AI, knowledge bases, and data sources. It displays suggested responses, recommended actions, and links to information sources based on the customer inquiry.



Step-by-step agent guides streamline agent workflows by providing guidance on how to handle or process next steps during customer interactions.



The agent workspace displays the following customer data:

Customer profile data: Contact information that allows agents to view and update customer details.
IVR data: Agents can view information collected during the IVR interaction, such as menu selections or chatbot intents.
The agent workspace provides the following agent assistance:

Step-by-step guides: IVR designers can create workflows to display dynamic views suggesting actions for agents during customer interactions.
Responses, recommendations, and information links: Using Contact Lens real-time contact intent identification, Amazon Q in Connect surfaces suggested responses, recommended actions, and relevant links. Agents can also manually search knowledge articles.
In addition to the built-in features of the agent workspace described above, organizations can integrate their home-grown or partner-built applications.

Considerations
There are a few considerations you should be aware of when using agent applications:

Security permissions: Organizations must implement proper security policies and permissions for their users based on roles and access levels required. Security profiles provide secure role-based access to specific areas of the Amazon Connect application. One of the required agent security permissions is access to the CCP. Agents need this security permission to handle incoming contacts in the CCP or agent workspace 
Service quotas: Administrators must verify and adjust service quotas as needed for Amazon Connect and related AWS services. Recommended quotas include Number of users per instance, Concurrent real-time calls with analytics, and Concurrent chat analytics jobs. 
Pricing: Amazon Connect has a flexible pricing model that allows scaling the number of users at no additional cost. However, organizations should carefully review and calculate the pricing of specific features and functionality they enable in agent workflows to avoid unexpected costs
