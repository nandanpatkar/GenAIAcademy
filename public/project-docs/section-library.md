# Library

Six reference destinations. Two are generated archives, three are user-curated collections backed by Supabase, and one talks to the GitHub API.

## Manual

![The Missing Manual.](/docs-shots/sections/manual.jpg)

Sets `showManual` and an active phase; the panel is `src/components/ManualViewer.jsx`.

The content comes from `themissingmanual/`, which is an **independently deployed product** in this repository — Rust plus SvelteKit plus Docker, with its own build and its own deploy target. The root `npm run build` does not touch it. What the SPA reads is the output of `npm run build:manual-path` (`scripts/build_manual_path.mjs`), which is in the root build chain, plus `scripts/build_manual_data.py`.

## Quick Reference

![Quick Reference.](/docs-shots/sections/quick-reference.jpg)

Sets `showReference` and an active topic; the panel is `src/components/ReferenceViewer.jsx`.

215 reference sheets, generated by `npm run build:reference` (`scripts/build_reference_data.py`) from the corpus in `reference/source/_posts/`. The script writes `src/data/referenceData.js` and copies the posts into `public/reference/`.

> [!IMPORTANT]
> This is the one generator a fresh clone cannot skip. `src/data/referenceData.js` is imported at module scope and is not committed, so `npm run dev` fails without it. Run `npm run build:reference` once after cloning.

## Resources

![Resources.](/docs-shots/sections/resources.jpg)

Tool home `resources`, then `src/components/ResourceManager.jsx` behind `showResources` (with `src/components/ResourcePanel.jsx` for a single entry).

Learner-added resources persist to `user_custom_resources`; the local mirror is `src/store/customResourcesStore.js`. This panel also hosts the "Import Playlist" feature, which calls `/api/youtube-playlist` with a playlist URL and expands it through the YouTube Data API.

## Blog

![Blog.](/docs-shots/sections/blog.jpg)

Tool home `blog`, then `src/pages/blog/BlogPage.jsx`. Its nav case is unusual — the fallback branch toggles an expanded state and issues a hub navigation rather than setting a single flag:

```javascript
case "blog":
  if (p.onOpenToolHome) p.onOpenToolHome("blog");
  else { if (setIsBlogExpanded) setIsBlogExpanded(!isBlogExpanded); if (p.onHubNav) p.onHubNav({ view: 'blog', year: null, isAI: false }); }
  break;
```

Backed by `src/services/blogCatalogService.js`, with favourites in the `blog_favorites` table and `src/store/favoriteBlogsStore.js`. Content is prepared by `scripts/process_blogs.py`.

## Saved Links

![Saved Links.](/docs-shots/sections/saved-links.jpg)

Sets an initial tab, then `showLinks`; the panel is `src/components/LinksCompanion.jsx`. Persists to `user_links`.

`links.txt` at the repo root is a very large source file for this feature and is one reason the repository is heavy to clone.

## GitHub

![GitHub.](/docs-shots/sections/github.jpg)

The panel is `src/components/GitHubHub.jsx` behind `showGitHubHub`, with `src/components/github/` for its parts and `src/services/githubService.js` for API access.

`VITE_GITHUB_TOKEN` is optional here — it exists only to raise the API rate limit. Without it the panel works against the unauthenticated limits.
