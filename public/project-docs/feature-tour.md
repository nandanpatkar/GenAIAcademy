# Feature tour

Every screenshot on this page was captured from this repository running locally with `npm run dev`. Each section names the component behind the surface so you can go from what you see to where it lives.

## Entry

An unauthenticated visitor lands on Home 3.0, a full-screen scroll-driven landing page with a Three.js scene. A product tour overlays it on first visit and can be skipped.

![Home 3.0, the landing page. The step rail on the right drives a scrolling narrative.](/docs-shots/landing.jpg)

`src/pages/HomePage3.jsx` · `src/components/Home3.jsx` · `src/components/Home3Scenes.jsx`

Sign-in has two modes, Learner and Admin, plus Google OAuth.

![The sign-in screen.](/docs-shots/sign-in.jpg)

`src/components/AuthInterface.jsx` · `src/contexts/AuthContext.jsx`

## The shell

Once signed in, the layout is a persistent grouped sidebar and one full-screen panel. Every sidebar entry swaps the panel.

![The signed-in shell.](/docs-shots/home-dashboard.jpg)

`src/App.jsx` · `src/components/Sidebar.jsx` · `src/components/SidebarModern.jsx`

Sections run Learn, Practice, Python Labs, Data Science, Visual Learning, AlgoWar, Labs, Learn API, Agents, AI from Scratch, Exams and Certification, Library, Career, Community, More tools — and, now, About.

![The grouped sidebar.](/docs-shots/sidebar.jpg)

`⌘K` opens a fuzzy search palette over the curriculum and a set of static destinations.

![The global search palette.](/docs-shots/search-palette.jpg)

`src/components/GlobalSearchPalette.jsx` · `src/utils/buildSearchIndex.js`

## Learn

Three roadmap treatments render the same curriculum model differently — a graph, a driving metaphor, and a scroll-flown world. They are the one part of the product that renders nothing useful without live data: the nodes come from the curriculum row in Supabase, so a signed-out or unpopulated account shows an empty canvas.

`src/components/RoadmapGraph.jsx` · `src/components/Roadmap2.jsx` · `src/pages/roadmap/Roadmap3.jsx`

The curriculum itself is a ~600 KB module loaded on demand through a shared promise, so it never sits in the entry chunk.

## Practice

**Code Lab** is the judge-backed problem set: 322 problems mapped to 70 interview patterns, each with a worked statement, judge-verified tests and a reference solution. It tracks a streak, a weekly goal and a year heatmap.

![Code Lab.](/docs-shots/code-lab.jpg)

`src/pages/LeetCodePage.jsx` · `src/components/leetcode/` · `api/leetcode-judge.js` · `api/_lib/leetcodeJudge.js`

**Coding Practice** is the in-browser Python environment, running Pyodide through `react-py` with Monaco for editing.

![Coding Practice.](/docs-shots/coding-practice.jpg)

`src/components/PythonIDE.jsx` · `src/config/monacoLoader.js`

**AI Playground** is where provider-backed experimentation happens, dispatching through the shared AI service.

![AI Playground.](/docs-shots/ai-playground.jpg)

`src/pages/playground/SystemDesignPlayground.jsx` · `src/services/aiService.js`

## Labs

Dozens of self-contained interactive labs covering retrieval, agents, tool calling, evaluation, classical ML, deep learning and statistics. Each is a registry entry in `sidebarRegistry.js` under `LAB_ITEM_IDS`, and all of them are reached through the single Labs hub rather than individual sidebar entries.

![The Labs hub.](/docs-shots/labs.jpg)

`src/components/LabsHub.jsx` · `src/labs/`

> [!NOTE]
> Several labs teach retrieval and RAG concepts by simulation. None of them runs a real vector store — there is no embedding or retrieval infrastructure in this repository.

## Agents & documentation archives

The LangChain, LangGraph, Deep Agents, LangSmith, Strands and AWS AgentCore viewers read large external documentation archives in-app. Pages are fetched on demand from R2 through a Cloudflare Worker, rewritten same-origin by `vercel.json`.

![An archive viewer: product rail, reading column, on-this-page rail.](/docs-shots/agents-docs.jpg)

`src/components/StrandsDocs.jsx` · `src/components/LangChainMarkdown.jsx` · `src/components/AgentCoreViewer.jsx`

The renderer in `LangChainMarkdown.jsx` is shared. It handles Mermaid diagrams, callouts, language tabs, cards, click-to-zoom images and cross-references — this documentation section reuses it rather than adding a second renderer.

## Career

**Interview Prep** is a large question bank with a lazily-fetched index — roughly 14 MB, deliberately kept out of both the bundle and the main search index.

![Interview Prep.](/docs-shots/interview-prep.jpg)

`src/components/InterviewPrep.jsx` · `scripts/build_interview_index.mjs`

Alongside it: a Retell-backed voice interviewer, a Gemini Live data-science interviewer, an emotional-support companion, and Job Scout — the Python agent running on Render.

`src/pages/interviewer/` · `src/pages/gemini-interviewer/` · `src/pages/emotional-support/` · `src/pages/jobscout/`

## Vendored surfaces

Some panels are not React at all. They are pre-built bundles in `public/`, iframed by a thin wrapper component: the Angular AWS simulator, a Next.js Git-learning game, a Kubernetes 3D simulator, a diagram-as-code tool, a codebase visualiser, and a self-hosted workspace app repurposed as in-app notes.

Treat these as integration contracts rather than source. Their build scripts often cannot run on a fresh clone — see [Content pipeline](doc:content-pipeline).
