# Loop in C++

Loops are used in programming to **execute a block of code repeatedly** until a specific condition is met. They help reduce repetitive code and make programs more efficient.

Two commonly used loops in C++ are:

- **for loop**
- **while loop**

# For Loop

A **for loop** is typically used when the **number of iterations is known in advance**. It combines initialization, condition checking, and iteration in a single line.

A `for` loop consists of three main components:

1. **Initialization** – Initializes the loop control variable.
2. **Condition** – Determines whether the loop should continue running.
3. **Iteration Expression** – Updates the loop variable after each iteration.
