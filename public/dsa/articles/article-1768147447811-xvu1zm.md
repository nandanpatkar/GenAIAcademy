## Problem Statement

Given an array ***words*** consisting of unique strings, your goal is to find all possible **palindrome pairs**. A palindrome pair is defined as a pair of indices ***(i, j)*** such that:

1. ***0 <= i, j < words.length***
2. ***i != j***
3. The concatenated string ***words[i] + words[j]*** forms a palindrome.

***Note:*** A **palindrome** is a string that reads the same forwards and backwards.

Your task is to return an array of all such pairs ***(i, j)*** that meet these criteria from the provided list ***words***.

### Example 1

> [!NOTE]
> **INFO**
> **Input:** words = ['abcd', 'dcba', 'lls', 's', 'sssll']
> **Output:** [[0, 1], [1, 0], [2, 4], [3, 2]]
> **Explanation: **Palindrome pairs: words[0]+words[1] = 'abcddcba', words[1]+words[0] = 'dcbaabcd', words[3]+words[2] = 'slls', words[2]+words[4] = 'llssssll'.

### Example 2

> [!NOTE]
> **INFO**
> **Input:** words = ['bat', 'tab', 'cat']
> **Output:** [[0, 1], [1, 0]]
> **Explanation:** Palindrome pairs: words[0]+words[1] = 'battab', words[1]+words[0] = 'tabbat'.

### Example 3

> [!NOTE]
> **INFO**
> **Input:** words = ['a', '']
> **Output: **[[0, 1], [1, 0]]
> **Explanation: **The empty string can form a palindrome with any single character.

### Constraints

- 1 <= **words.length** <= 10000
- 0 <= **words[i].length** <= 100
- **words[i]** consists of lowercase English letters.

## Real-Life Analogy

Imagine you're organizing a dance competition where pairs of dancers must perform together. Each dancer has a unique signature move (represented by a string), and when two dancers combine their moves in sequence, they create a routine.

The special requirement: **the combined routine must be symmetrical** - it should look the same whether you watch it forward or in reverse (like a palindrome).

Think of it like this:

- Dancer A does move "abc"
- Dancer B does move "cba"
- Combined routine: "abccba" - perfectly symmetrical!

Your job as the organizer is to find all valid pairs of dancers whose combined routines create this beautiful symmetry. You can't pair a dancer with themselves, and the order matters (A→B might work even if B→A doesn't).

This is exactly like finding palindrome pairs - you're matching strings where their concatenation creates a palindrome!

## Brute-Force Approach

### Intuition

The most straightforward way is to try every possible pair of words and check if their concatenation forms a palindrome. It's like testing every possible dance pair combination to see which ones create symmetrical routines.

For each word at position **i**, we pair it with every other word at position **j** (where i ≠ j), concatenate them as **words[i] + words[j]**, and check if the result is a palindrome.

### Algorithm

1. **Iterate through all pairs of words using two nested loops** because we need to check every possible combination of two words to see if their concatenation forms a palindrome.
2. - Outer loop: Let **i go from 0 to n-1, where n** is the number of words.
  - Inner loop: Let **j go from 0 to n-1 to pair words[i]** with every other word including itself initially, but we will handle the same index next.
3. **Skip pairs with the same index** because concatenating a word with itself is not required unless explicitly allowed. **If i == j, continue to the next iteration**.
4. **Concatenate the two words** to form a combined string **combined = words[i] + words[j]** because we are checking if this specific ordering forms a palindrome.
5. **Check if the concatenated string is a palindrome** by using two pointers because comparing characters from both ends inward is efficient and directly checks the palindrome property.
6. - Initialize **left = 0** and **right = combined.length - 1**. While **left < right**, compare **combined[left]** with **combined[right]**.
  - - If they are equal, move **left++** and **right--** because the outer characters match and we need to check the inner ones.
    - If they are not equal, break the loop because the string cannot be a palindrome.
  - If the loop completes without mismatches, the string is a palindrome.
7. **Store the valid pair of indices** **[i, j]** in the result array because this pair forms a palindrome when concatenated.
8. **Return **the** result** containing all pairs of indices where the concatenated words form palindromes.

### C++ Implementation

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    // Brute Force Approach
    vector<vector<int>> palindromePairsBrute(vector<string>& words) {
        vector<vector<int>> result;
        int n = words.size();

        // Try all possible pairs
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i != j) {  // Can't pair with itself
                    string combined = words[i] + words[j];
                    if (isPalindrome(combined)) {
                        result.push_back({i, j});
                    }
                }
            }
        }

        return result;
    }

private:
    // Helper function to check if a string is palindrome
    bool isPalindrome(const string& s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }
};
```

### Complexity Analysis

#### Time Complexity: **O(N****2 **** x  K)**

- (where, **'n'** = number of words in the array and **'k' **= average length of words)
- The outer loop iterates over all **n **words.
- For each word, the inner loop again iterates over all **n ** words.
- This results in a total of **n × n = n² **word pairs being evaluated.
- For each pair:
- - The two strings are concatenated, which takes **O(k)** time.
  - The concatenated string is then checked for being a palindrome, which takes **O(2k) ≈ O(k)** time.
- Therefore, each pair requires **O(k)** time.
- Overall time complexity becomes: **n****2****×O(k)=O(n****2****×k)**

#### Space Complexity: O(K)

- (where** 'k':** average length of the words)
- A temporary string of length up to **2k** is created during concatenation, which requires **O(k)** space.
- Apart from this temporary string, only a few constant-sized variables are used.
- The space used to store the output is excluded from auxiliary space calculation.
- Hence, the total auxiliary space complexity is: **O(k).**

## Optimal Approach

### Intuition

The brute-force approach is inefficient because it checks many word pairs that can never form a palindrome. Instead, we can optimize by using a key insight: for **words[i] + words[j]** to be a palindrome, one of three conditions must hold either one word is an empty string and the other is already a palindrome, or one word is the exact reverse of the other, or the word can be split into two parts such that one part is a palindrome and the reverse of the remaining part exists as another word. By focusing only on these valid cases, we avoid unnecessary comparisons and make the solution significantly more efficient.

### Algorithm

1. Firstly, we build a HashMap where the key is each word from the list and the value is its index, which allows O(1) lookup when checking reversed strings. Next, we iterate through each word in the list and treat its index as **i**. For every word, we attempt to form palindrome pairs using three systematic cases.
2. **Case 1 (Empty String):** We check if the empty string** ""** exists in the map. If it does and the current word is not empty and is itself a palindrome, then concatenating the word with the empty string in either order still forms a palindrome. Hence, we add the pairs **(i, emptyIndex)** and **(emptyIndex, i)**.
3. **Case 2 (Exact Reverse):** We reverse the entire current word and check if this reversed string exists in the map. If it exists and its index **j** is different from **i**, then **words[i] + words[j]** (which is** word + reverse(word)**) forms a palindrome, so we add the pair **(i, j)**.
4. **Case 3 (Partial Splits):** For the current word, we try every possible split position from **1** to **length - 1** (excluding the endpoints to avoid redundancy with Cases 1 and 2), dividing it into **left** and **right** substrings. For each split, we check two subcases:
5. 1. **Left is Palindrome:** If the **left** substring is a palindrome, we reverse the **right** substring and check if it exists in the map with index **j ≠ i**. If found, then** words[j] + words[i]** (which equals **reverse(right) + left + right**) forms a valid palindrome because the left part is already symmetric and **reverse(right)** mirrors **right**. We add the pair **(j, i)**.
  2. **Right is Palindrome:** If the **right** substring is a palindrome, we reverse the **left** substring and check if it exists in the map with index **j ≠ i**. If found, then **words[i] + words[j]** (which equals **left + right + reverse(left)**) forms a valid palindrome because the right part is already symmetric and **reverse(left)**mirrors **left**. We add the pair **(i, j)**.
6. Throughout the process, we ensure no duplicate pairs are added by always checking **i ≠ j **before adding any pair. After processing all words and all cases, the collected index pairs represent all valid palindrome pairs, which we return as the result.

```cpp
class Solution {
public:
    // Optimal Approach using HashMap
    vector<vector<int>> palindromePairs(vector<string>& words) {
        vector<vector<int>> result;

        // Build word -> index map
        unordered_map<string, int> wordMap;

        for (int i = 0; i < words.size(); i++) {
            wordMap[words[i]] = i;
        }

        // Process each word
        for (int i = 0; i < words.size(); i++) {
            string word = words[i];

            // Case 1: Check if empty string exists
            if (wordMap.count("") && word != "" && isPalindrome(word)) {
                int emptyIdx = wordMap[""];

                result.push_back({i, emptyIdx});
                result.push_back({emptyIdx, i});
            }

            // Case 2: Check if exact reverse exists
            string reversedWord = word;
            reverse(reversedWord.begin(), reversedWord.end());

            if (wordMap.count(reversedWord) && wordMap[reversedWord] != i) {
                result.push_back({i, wordMap[reversedWord]});
            }

            // Case 3: Try all splits
            for (int j = 1; j < word.length(); j++) {

                string left = word.substr(0, j);
                string right = word.substr(j);

                // If left is palindrome
                if (isPalindrome(left)) {

                    string reversedRight = right;
                    reverse(reversedRight.begin(), reversedRight.end());

                    if (wordMap.count(reversedRight) &&
                        wordMap[reversedRight] != i) {

                        result.push_back({wordMap[reversedRight], i});
                    }
                }

                // If right is palindrome
                if (isPalindrome(right)) {

                    string reversedLeft = left;
                    reverse(reversedLeft.begin(), reversedLeft.end());

                    if (wordMap.count(reversedLeft) &&
                        wordMap[reversedLeft] != i) {

                        result.push_back({i, wordMap[reversedLeft]});
                    }
                }
            }
        }

        return result;
    }

private:
    // Helper function to check palindrome
    bool isPalindrome(string s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
};
```

```java
import java.util.*;

class Solution {
    // Optimal Approach using HashMap
    public List<List<Integer>> palindromePairs(String[] words) {
        List<List<Integer>> result = new ArrayList<>();
        
        // Build word to index map
        Map<String, Integer> wordMap = new HashMap<>();
        for (int i = 0; i < words.length; i++) {
            wordMap.put(words[i], i);
        }
        
        // Process each word
        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            
            // Case 1: Check if empty string exists
            if (wordMap.containsKey("") && !word.equals("") && isPalindrome(word)) {
                int emptyIdx = wordMap.get("");
                result.add(Arrays.asList(i, emptyIdx));
                result.add(Arrays.asList(emptyIdx, i));
            }
            
            // Case 2: Check if exact reverse exists
            String reversedWord = new StringBuilder(word).reverse().toString();
            if (wordMap.containsKey(reversedWord) && wordMap.get(reversedWord) != i) {
                result.add(Arrays.asList(i, wordMap.get(reversedWord)));
            }
            
            // Case 3: Try all splits
            for (int j = 1; j < word.length(); j++) {
                String left = word.substring(0, j);
                String right = word.substring(j);
                
                // If left is palindrome, check if reverse of right exists
                if (isPalindrome(left)) {
                    String reversedRight = new StringBuilder(right).reverse().toString();
                    if (wordMap.containsKey(reversedRight) && wordMap.get(reversedRight) != i) {
                        result.add(Arrays.asList(wordMap.get(reversedRight), i));
                    }
                }
                
                // If right is palindrome, check if reverse of left exists
                if (isPalindrome(right)) {
                    String reversedLeft = new StringBuilder(left).reverse().toString();
                    if (wordMap.containsKey(reversedLeft) && wordMap.get(reversedLeft) != i) {
                        result.add(Arrays.asList(i, wordMap.get(reversedLeft)));
                    }
                }
            }
        }
        
        return result;
    }
    
    // Helper function to check if a string is palindrome
    private boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;
        
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### Python Implementation

```python
class Solution:

   
    def palindromePairs(self, words):
        result = []

        # Build word -> index map
        wordMap = {}

        for i, word in enumerate(words):
            wordMap[word] = i

        # Process each word
        for i, word in enumerate(words):

            # Case 1: Check if empty string exists
            if "" in wordMap and word != "" and self.isPalindrome(word):

                emptyIdx = wordMap[""]

                result.append([i, emptyIdx])
                result.append([emptyIdx, i])

            # Case 2: Check if exact reverse exists
            reversedWord = word[::-1]

            if reversedWord in wordMap and wordMap[reversedWord] != i:
                result.append([i, wordMap[reversedWord]])

            # Case 3: Try all splits
            for j in range(1, len(word)):

                left = word[:j]
                right = word[j:]

                # If left is palindrome
                if self.isPalindrome(left):

                    reversedRight = right[::-1]

                    if reversedRight in wordMap and wordMap[reversedRight] != i:
                        result.append([wordMap[reversedRight], i])

                # If right is palindrome
                if self.isPalindrome(right):

                    reversedLeft = left[::-1]

                    if reversedLeft in wordMap and wordMap[reversedLeft] != i:
                        result.append([i, wordMap[reversedLeft]])

        return result

    # Helper function to check palindrome
    def isPalindrome(self, s):

        left = 0
        right = len(s) - 1

        while left < right:

            if s[left] != s[right]:
                return False

            left += 1
            right -= 1

        return True
```

### Complexity Analysis

#### Time Complexity: **O(N x K****2****)**

- (where, **n** = number of words in the array and** k** = average length of words).
- Building HashMap: O(n × k) for inserting n words.
- For each word (n iterations):  - Case 1 (empty string): O(k) for palindrome check.
  - Case 2 (reverse): O(k) for reversing + O(1) for HashMap lookup.
  - Case 3 (all splits):
  - - k-1 possible splits.
    - Each split: O(k) for substring creation + O(k) for palindrome check + O(k) for reversing.
    - Total per word: O(k × k) = O(k²).
- Total: O(N) + O(N × K²) = **O(N × K²).**

#### Space Complexity: O(N x K)

- (where, **n** = number of words and **k **= average length of words).
- HashMap storage: O(n × k) for storing n words of average length k.
- Temporary strings for reversal and substrings: O(k).
- Result list not counted (output space).
- Total auxiliary space: **O(n × k).**
