## Problem Statement

Given an array of integers, determine the mode of the array. The mode is the element that appears most frequently in the array. If there is more than one element with the highest frequency of appearances, return the smallest of these elements.

## Example 1

> [!NOTE]
> **INFO**
> Example 1:
> 
> Input: Input: arr = [1, 2, 2, 3, 3, 3]
> 
> Output: 3
> 
> Explanation: 3 is the mode with the highest frequency.

## Example 2

> [!NOTE]
> **INFO**
> Example 2:
> 
> Input: Input: arr = [4, 5, 5, 6, 6]
> 
> Output: 5
> 
> Explanation: 5 and 6 have the same frequency, but 5 is smaller.

## Intuition

To determine the mode, we first need to know how many times each element appears in the array. This naturally leads to counting frequencies. Once the frequency of every element is known, the problem reduces to identifying the element with the highest count. In cases where two or more elements have the same frequency, the requirement to return the smallest element helps resolve the tie deterministically. Using a hash map allows us to efficiently store and retrieve the frequency of each number. After building this frequency map, a second traversal over the stored entries helps identify the correct mode while respecting the tie-breaking rule.

## Algorithm

**Step 1:** Create a hash map to store the frequency of each element in the array.

**Step 2:** Traverse the array and update the frequency of each element in the map.

**Step 3:** Initialize two variables: one to store the current mode and another to track the maximum frequency found so far.

**Step 4:** Iterate through the entries of the frequency map. For each element, update the mode if its frequency is greater than the current maximum. If the frequency is equal, update the mode only if the current element is smaller than the stored mode.

**Step 5:** Return the final value stored as the mode.





## Time Complexity: O(n)

**Explanation: **The array is traversed once to build the frequency map and once more (through the map entries) to determine the mode. Since the number of distinct elements is at most n, the overall time complexity is linear.

## Space Complexity: O(n)

**Explanation: **The hash map stores the frequency of each unique element in the array. In the worst case, all elements are distinct, requiring space proportional to the array size.
