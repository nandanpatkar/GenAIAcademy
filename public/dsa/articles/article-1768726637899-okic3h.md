## Problem Statement

In this problem, you need to determine if each string in a given array of strings ***queries*** matches a specified ***pattern*** using camelcase style. A string matches the pattern if you can insert any number of lowercase English letters into the pattern to reproduce the string exactly as it appears in the ***queries*** array.

A match is successful if all the uppercase letters in the ***pattern*** appear in the same order and at the same positions or earlier positions in the ***queries*** string.

### Example 1

> [!NOTE]
> **INFO**
> **Input:** queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FB"
> **Output:** [true, false, true, true, false]
> **Explanation: **The pattern **"FB"** matches a query if **F** and **B** appear in the same order as uppercase letters, with any number of lowercase letters allowed in between. **FooBar**, **FootBall**, and **FrameBuffer** satisfy this condition. **FooBarTest** and **ForceFeedBack** are rejected because they contain extra uppercase letters that are not part of the pattern.

### Example 2

> [!NOTE]
> **INFO**
> **Input:** queries = ["CodeHelp","CamelCaseMatch","CodingHelper"], pattern = "CH"
> **Output:**[true, false, true]
> **Explanation:** The pattern **"CH"** matches queries where **C** and **H** appear in order as uppercase letters, with any lowercase letters in between.** CodeHelp** and **CodingHelper** satisfy this order, while **CamelCaseMatch** does not.

### Example 3

> [!NOTE]
> **INFO**
> **Input:** queries = ["XMLParser","XPathLibrary","XenonLight"], pattern = "XL"
> **Output: **[false, false, true]
> **Explanation: **The pattern **"XL"** requires **X** followed by **L** as uppercase letters in order. Only **XenonLight** satisfies this sequence, while **XMLParser** and **XPathLibrary** do not.

### Constraints

- 1 <= **queries.length** <= 100
- 1 <= **queries[i].length, pattern.length** <= 100
- **queries[i]** and pattern contain only lowercase and uppercase English letters.

## Brute-Force Approach

### Intuition

The most straightforward way is to use **two pointers** to traverse both the query string and the pattern simultaneously. We try to match each character of the pattern with characters in the query, allowing lowercase letters in the query to be skipped. If we find an uppercase letter in the query that doesn't match the current pattern character, or if we can't match all pattern characters, the query doesn't match.

The key insight is:

- **Lowercase letters in query** can be anywhere (they're insertions)
- **Uppercase letters in query** must match pattern uppercase letters in exact order
- **Extra uppercase letters in query** that aren't in pattern mean NO match

### Algorithm

1. Initialise** two pointers because we need to traverse both the pattern and query string simultaneously to check character-by-character matching.**
2. 1. **patternIndex = 0** to track position in pattern.
  2. **queryIndex = 0** to track position in query.
3. **Iterate through the query string** using **queryIndex** from 0 to **query.length - 1** because we need to examine every character in the query to ensure no invalid uppercase letters exist.**For each character in query**:
4. 1. **Case 1:** Current query character matches current pattern character. If **query[queryIndex] == pattern[patternIndex]**: Increment both pointers (**patternIndex++** and **queryIndex++**) because we have successfully matched this character and can move to the next ones in both strings.
  2. **Case 2: Current query character is lowercase. **Else if **query[queryIndex]** is lowercase (check using **isLowerCase()**), Only increment **queryIndex++** because lowercase letters are allowed insertions and don't need to match the pattern.
  3. **Case 3: Current query character is uppercase but doesn't match. **Else (the query character is uppercase but doesn't match current pattern character), Return **false** immediately because we found an extra uppercase letter in the query that's not in the pattern, which violates the matching rule.
5. **3. After the loop, verify all pattern characters were matched**:  1. Check if **patternIndex == pattern.length **because we need to ensure every character in the pattern was found in the query.
  2. If yes, return **true** (successful match).
  3. If no, return **false** (pattern has unmatched characters).
6. **Apply this process to each query string** and store results in a boolean array because we need to check all queries independently.
7. **Return the result array** containing match status for all queries.

### C++ Implementation

```cpp
#include <vector>
#include <string>
#include <cctype>
using namespace std;

class Solution {
public:
    // Brute Force Approach - Two Pointer Method
    vector<bool> camelMatch(vector<string>& queries, string pattern) {
        vector<bool> result;

        // Check each query against the pattern
        for (string& query : queries) {
            result.push_back(isMatch(query, pattern));
        }

        return result;
    }

private:
    // Helper function to check if a query matches the pattern
    bool isMatch(string& query, string& pattern) {
        int patternIndex = 0;
        int queryIndex = 0;

        // Traverse the query string
        while (queryIndex < query.length()) {
            // Case 1: Characters match
            if (patternIndex < pattern.length() &&
                query[queryIndex] == pattern[patternIndex]) {
                patternIndex++;
                queryIndex++;
            }
            // Case 2: Query character is lowercase (allowed insertion)
            else if (islower(query[queryIndex])) {
                queryIndex++;
            }
            // Case 3: Query has uppercase letter not in pattern
            else {
                return false;
            }
        }

        // Check if all pattern characters were matched
        return patternIndex == pattern.length();
    }
};
```

        # Check each query against the pattern

            result.append(self.isMatch(query, pattern))

        queryIndex = 0

            if (patternIndex < len(pattern) and
                    query[queryIndex] == pattern[patternIndex]):
                patternIndex += 1
                queryIndex += 1

            elif query[queryIndex].islower():
                queryIndex += 1

            # Case 3: Query has uppercase letter not in pattern
            else:
                return False

        # Check if all pattern characters were matched
        return patternIndex == len(pattern)

### Complexity Analysis

#### Time Complexity: O(N × (Q + P))

- (where **'N'** = number of queries, **'Q' **= average length of query strings and **'P' ** = length of pattern).
- **Outer loop:** Iterate over N queries → **O(N)**
- **Per query:**
- - Traverse query (Q chars) and compare with pattern → **O(Q)**
  - Pattern pointer moves at most P times → **O(P)** (≤ Q)
  - Final check → **O(1)**
- **Total per query:** O(Q + P) → typically O(Q) if P ≤ Q**. Overall**, O(N × (Q + P))

#### Space Complexity: O(1)

- **Input Storage**
- - **queries** array: **O(N × Q)**
  - **pattern** string: **O(P)**
*(Input space is ****not counted**** in auxiliary space)*
- **Output List**
- - Stores **N boolean values** for each query
  - Space: **O(N)**
*(Output space is also ****not counted**** in auxiliary space)*
- **Auxiliary Space (Extra Variables)**
- - Pointers: **patternIndex, queryIndex** → **O(1)**
  - Loop counters → **O(1)**
  - No recursion stack or additional data structures used.

## Optimal Approach

### Intuition

The brute-force approach is already efficient with **O(N × Q)** time complexity, but we can make it clearer using the **two-pointer technique**. The main idea is simple: **pattern characters must appear in order**, **lowercase letters are allowed anywhere**, and **any extra uppercase letter causes failure**. While no faster algorithm exists, we can improve clarity and efficiency by adding **early termination** when an extra uppercase is found and **separating the matching logic** for readability.

### Algorithm

1. Create a separate function to check if a single query matches the pattern. This modularises** the code** and keeps the logic clean. Instead of embedding everything inside a loop over queries, this function handles the **core matching logic** for one query.
2. We use two pointers to compare the query and pattern:

- **patternIndex** → tracks our current position in the pattern
- **queryIndex** → tracks our current position in the query

This allows us to **walk through both strings simultaneously**, maintaining the order requirement of the pattern.

1. Loop through the query characters one by one:

- **If the query character matches the current pattern character** → move **both pointers forward, **because we successfully matched this part of the pattern, so we advance in the pattern and the query.
- **If the query character is lowercase** → move **only the query pointer** as lowercase letters are allowed anywhere as “insertions,” so we don’t move the pattern pointer.
- **If the query character is uppercase but doesn’t match the pattern** → return **false** immediately because this is an **extra uppercase letter**, violating the pattern.

1. After traversing the query, check if **all characters in the pattern were matched**:

- If **patternIndex == pattern.length** → the query matches the pattern.
- Otherwise → the query is missing some main points → **return false**

1. Finally, iterate over all queries. So, For each query, call **isMatch(query, pattern)**. Collect the boolean results (**true** or **false**) for each query. And **return** the array of **results**.

### Complexity Analysis

#### Time Complexity: **O(N × (Q + P))**
(Where **N** = number of queries, **Q** = average query length, **P** = pattern length)

- **Outer Loop:** Process all **N** queries → **O(N)**
- **For each query:**  - Traverse the query of length **Q** exactly once → **O(Q)**
  - Each iteration performs only constant-time operations (character comparison, pointer update, lowercase check) → **O(1)**
  - The pattern pointer advances at most **P** times, but these advances occur within the same traversal and do not add an extra pass.
  - Final check (**patternIndex == pattern.length()**) → **O(1)**
- **Time per query:** **O(Q)**
- **Overall Time Complexity:** **O(N × Q)**

### **Space Complexity: O(1)**

- **Input Storage**  as queries array **O(N × Q)**, pattern **O(P)** which is  **not counted.**
- **Output Storage**  as result list **O(N)** which is  **not counted.**
- **Auxiliary Space (variables only)**
- - Loop counters, **patternIndex**, **queryIndex**, temporary query references which is **O(1).**
  - No recursion, no extra data structures, no string copies.
- **Total Auxiliary Space:** **O(1)**
