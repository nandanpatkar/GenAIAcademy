# Namaste Dunia in C++ (First Program)

## Introduction to the `int main()` Function

### Explanation:

- **`int`** → This is the **return type** of the function. It means the `main()` function will return an **integer value** when the program finishes.
- **`main()`** → This is the **starting function of every C++ program**. The program execution always begins from `main()`.
- **`{ }`** → These **curly braces define the body of the function**, where the program code is written.

## Introduction to the `return` Statement

### Explanation:

- `return 0;` is used to **end the ****`main()`**** function** and send a value back to the **operating system**.
- **`return`** → A keyword used to **exit a function** and return a value.
- **`0`** → Indicates that the program **executed successfully without any errors**.
- So, `return 0;` means **the program finished running successfully**.

# First Program in C++

### Explanation:

- `#include <iostream>`
- - This is a **header file**.
  - It allows the program to use **input and output features** like `cout` and `cin`.
- `using namespace std;`
- - `std` stands for **standard namespace** in C++.
  - It contains standard objects like `cout`, `cin`, and `end`.
  - Writing this line lets you use `cout` directly instead of writing `std::cout`.
- **`cout << "Namaste Dunia";`**
- - `cout` is used to **print output on the screen**.
  - `<<` is called the **insertion operator**.
  - `"Namaste Dunia"` is the **text that will be displayed on the console**.
  - Output as **Namaste Dunia**.
