## Problem Statement

In this problem, you are given an array of integers, and your task is to shift all its elements to the right by one position. This means that each element should move one place to the right, and the last element of the array should wrap around and move to the first position. This kind of operation is commonly known as a right rotation of the array.

For example, consider an array ***[1, 2, 3, 4]***. After performing a right shift, it will transform into ***[4, 1, 2, 3]***.

Your task is to implement this rotation functionality efficiently, maintaining the circular nature of the shift.

> Output: [1]

## Intuition

A right shift by one position essentially means:

- The **last element** of the array becomes the **first element**.
- Every other element shifts **one index to the right**.

Since the problem does not require modifying the original array in place, we can create a **new list** to store the shifted elements. By first inserting the last element into the new list and then appending the remaining elements in order, we can achieve the desired rotation efficiently and clearly. This approach keeps the logic simple, avoids unnecessary swaps, and preserves the original array.

## Algorithm

**Step 1:** Check if the array is empty. If it is empty, return it immediately, as no shifting is possible.

**Step 2:** Create a new list shifted with the same capacity as the input array.

**Step 3:** Add the last element of the original array to the beginning of the shifted list.

**Step 4:** Iterate from index 1 to the end of the array: Add the element at position i - 1 from the original array to the shifted list.

**Step 5:** Return the shifted list, which now represents the array after a right shift by one position.





## Time Complexity: O(n)

**Explanation: **

- The algorithm iterates through the array once.
- Each element is added to the new list exactly once.
- Therefore, the time complexity grows linearly with the size of the input array.

## Space Complexity: O(n)

**Explanation: **

- A new list of size n is created to store the shifted elements.
- Since the original array remains unchanged, additional linear space is required.
