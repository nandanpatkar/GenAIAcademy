## Problem Statement

Given an array of strings called ***words***, your task is to identify the ***k*** most frequent words and return them in a list ordered by frequency. If two or more words have the same frequency, sort them lexicographically. This problem focuses on efficiently counting occurrences and sorting based on frequency and lexicographical order.

### Example 1

> [!NOTE]
> **INFO**
> **Input:** words = ["i", "love", "leetcode", "i", "love", "coding"], k = 2
> **Output:** ["i", "love"] 
> **Explanation: **The words "i" and "love" are the most frequent with a frequency of 2. Since the task is to return only the top 2 words, ["i", "love"] becomes the answer.

### Example 2

> [!NOTE]
> **INFO**
> **Input:** words = ["the", "day", "is", "sunny", "the", "the", "the", "sunny", "is", "is"], k = 4
> **Output:** ["the", "is", "sunny", "day"]
> **Explanation:**  The word **"the"** appears 4 times, followed by **"is"** with 3 occurrences. **"sunny"** appears 2 times, and **"day"** appears once. Since we need the top 4 frequent words and higher frequency words come first (with lexicographical order used only when frequencies tie), the correct result is **["the", "is", "sunny", "day"]**.

### Example 3

> [!NOTE]
> **INFO**
> **Input:** words = ["a", "b", "c", "a", "b", "c", "a"], k = 1
> **Output: **[a]
> **Explanation:** The word **"a"** appears **3 times**, which is more than **"b"** and **"c"**, each appears 2 times. Since **k = 1**, we return only the single most frequent word, which is **["a"]**.

### Constraints

- 1 <= **words.length** <= 50000
- 1 <= **words[i].length** <= 10
- **words[i] **consists of lowercase English letters.
- **1 <= k <= number of unique words.**

## Brute-Force Approach

### Intuition

The most straightforward approach is to count the frequency of each word using a HashMap, then sort all unique words based on two criteria: first by frequency (descending), and second by lexicographical order (ascending) for words with the same frequency. Finally, we take the first **k** words from the sorted list.

**The key steps are:**

1. **Count frequencies** , Use a HashMap to track how many times each word appears.
2. **Sort by custom comparator**, Sort based on frequency (higher first), then alphabetically (lower first).
3. **Take top k**, Extract the first k words from the sorted list.

### Algorithm

1. Firstly, we **create a frequency map** using a HashMap because we need to count how many times each word appears in the array, and HashMap provides O(1) average-case insertion and lookup. As we look up key as word (String) and Value as frequency count (Integer).
2. After creating the frequency map. Now we build** the frequency map** by iterating through the words array because we need to count all occurrences of each word.
3. - For each word in the array:
  - - If word exists in map, increment its count.
    - Otherwise, add word to map with count = 1.
  - This can be done using **map.put(word, map.getOrDefault(word, 0) + 1)**
4. Next,** extract all unique words** from the HashMap's keySet into a list because we need to sort these words according to our custom criteria. As we create a list from **map.keySet(). **This gives us all unique words that appeared in the input.
5. Now,** Sort the list using a custom comparator** because we have two sorting criteria that need to be applied in specific order.
6. - **Primary criterion:** Sort by frequency in descending order (higher frequency first).
  - - Compare **map.get(word2)** with **map.get(word1)**.
    - **Note: word2 - word1 for descending order.**
  - **Secondary criterion:** If frequencies are equal, sort lexicographically in ascending order
**Combined comparator logic:**
  - - Compare **word1.compareTo(word2). **
    - This ensures alphabetical order when frequencies match.
  - **Combined comparator logic: **

> [!NOTE]
> **INFO**
> If frequencies are different:
> 
>     return frequency comparison (descending: freq2 - freq1)
> 
> Else:
> 
>     return lexicographical comparison (ascending: word1.compareTo(word2))
7. **Extract the top k words** from the sorted list because we only need the k most frequent words. And use **list.subList(0, k)** to get the first k elements, or iterate and add first k words to result list.
8. At last, we** return the **result containing exactly k words in the required order.

### C++ Implementation

```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    // Brute Force Approach - HashMap + Sorting
    vector<string> topKFrequent(vector<string>& words, int k) {
        // Step 1: Build frequency map
        unordered_map<string, int> frequencyMap;
        for (string& word : words) {
            frequencyMap[word]++;
        }

        // Step 2: Extract all unique words
        vector<string> uniqueWords;
        for (auto& entry : frequencyMap) {
            uniqueWords.push_back(entry.first);
        }

        // Step 3: Sort with custom comparator
        sort(uniqueWords.begin(), uniqueWords.end(),
             [&](const string& word1, const string& word2) {
                 int freq1 = frequencyMap[word1];
                 int freq2 = frequencyMap[word2];

                 // Primary: Sort by frequency (descending)
                 if (freq1 != freq2) {
                     return freq1 > freq2;  // Higher frequency first
                 }

                 // Secondary: Sort lexicographically (ascending)
                 return word1 < word2;  // Alphabetical order
             });

        // Step 4: Extract top k words
        return vector<string>(uniqueWords.begin(), uniqueWords.begin() + k);
    }
};
```

import java.util.*;

class Solution {
    // Brute Force Approach - HashMap + Sorting
    public List<String> topKFrequent(String[] words, int k) {

        // Step 1: Build frequency map
        Map<String, Integer> frequencyMap = new HashMap<>();
        for (String word : words) {

        List<String> uniqueWords = new ArrayList<>(frequencyMap.keySet());

        // Step 3: Sort with custom comparator

            int freq1 = frequencyMap.get(word1);
            int freq2 = frequencyMap.get(word2);

            // Primary: Sort by frequency (descending)
            if (freq1 != freq2) {
                return freq2 - freq1; // Higher frequency first
            }

            // Secondary: Sort lexicographically (ascending)
            return word1.compareTo(word2); // Alphabetical order
        });

        // Step 4: Extract top k words
        return uniqueWords.subList(0, k);
    }
}

### Complexity Analysis

#### Time Complexity: O(N + U log U)

- (where, '**N'** is the total number of words and '**U'** is the number of unique words.).
- First, we traverse the entire array to build a frequency map, which takes **O(N)** time.
- Then, we extract all unique words from the map, which costs **O(U)** time.
- After that, we sort the unique words based on their frequency, taking **O(U log U)** time. Since word lengths are small, string comparison can be treated as constant.
- Finally, we pick the top `k` words, which takes **O(k)** time.
- So overall, the time complexity becomes **O(N + U log U)**.

#### Space Complexity: O(U)

- We use a HashMap to store the frequency of each unique word and a list to store those unique words, both of which take **O(U)** space.
- Sorting requires **O(log U)** stack space, and the result list stores `k` words (output space).
- So, the total auxiliary space complexity is **O(U)**.

## Optimal Approach

### Intuition

In the brute-force approach, we sort **all unique words**, even though we only need the **top k**. This becomes inefficient when the number of unique words (**U**) is much larger than **k**. To optimize this, we use a **Min-Heap (Priority Queue)** of size **k**. Instead of sorting all **U** words, we maintain a heap that stores only the **k best candidates so far**. This helps reduce unnecessary work and improves efficiency.

First, we build the frequency map as usual. Then, we iterate over the unique words and insert them into a **Min-Heap**. The heap is ordered so that the word with the **lowest frequency** (or worse lexicographical order in case of a tie) stays at the top. Whenever the heap size exceeds **k,** we remove the top element, which represents the **least deserving word** among the current top k. By the end of the process, the heap contains **exactly the k most frequent words**, without ever sorting all unique words.

### Algorithm

1. Firstly we build frequency map **using HashMap**, same as brute force approach because we still need to count all word occurrences. Then we Iterate through all words  to Store word as frequency mapping. SO, by this complexity** **will be O(N).
2. Next, we create a **Min-Heap (PriorityQueue) **with a custom comparator because we want to maintain only the **k** best words and efficiently remove the worst.
3. 1. Now we check the Comparator logic (Min-Heap for "worst" removal):
  2. 1. **Primary: **Lower frequency should be at heap top (to be removed first) and Compare freq1 vs freq2 → return freq1 - freq2.
    2. **Secondary**: If frequencies equal, lexicographically larger word at top and Compare **word2.compareTo(word1)** → reverse alphabetical order. This ensures the "least deserving" word is always at the heap top for easy removal.
4. Afterwards, we process the unique word from the frequency map because we need to consider all candidates for the top k positions. For each word we add word to heap, If heap size exceeds k. We remove the minimum element (poll). This removes the least frequent word, or if tied, the lexicographically larger word. After processing all words, heap contains exactly k elements, the top k most frequent words.
5. We extract words from heap because the heap currently has words in min-heap order, but we need them in our final output order. Poll all k words from heap into a temporary list and words come out in **"worst-first"** order (opposite of what we want).
6. Now we reverse the list as heap gives us words in ascending order of priority, but we want descending order (most frequent first). For this we use **'Collections.reverse()'** or build result in reverse. This gives us the correct final order as highest frequency first, alphabetical for ties.
7. At last, we return the result as containing exactly k words in the required order.

### C++ Implementation

```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    // Optimal Approach - HashMap + Min-Heap
    vector<string> topKFrequent(vector<string>& words, int k) {
        // Step 1: Build frequency map
        unordered_map<string, int> frequencyMap;
        for (string& word : words) {
            frequencyMap[word]++;
        }

        // Step 2: Create Min-Heap with custom comparator
        auto cmp = [&](const string& word1, const string& word2) {
            int freq1 = frequencyMap[word1];
            int freq2 = frequencyMap[word2];

            // Primary: Lower frequency at top (min-heap)
            if (freq1 != freq2) {
                return freq1 > freq2;
            }

            // Secondary: Lexicographically larger word at top
            return word1 < word2;
        };

        priority_queue<string, vector<string>, decltype(cmp)> minHeap(cmp);

        // Step 3: Process each unique word
        for (auto& entry : frequencyMap) {
            minHeap.push(entry.first);

            // Keep only k words in heap
            if (minHeap.size() > k) {
                minHeap.pop();  // Remove least deserving word
            }
        }

        // Step 4: Extract words from heap
        vector<string> result;
        while (!minHeap.empty()) {
            result.push_back(minHeap.top());
            minHeap.pop();
        }

        // Step 5: Reverse to get correct order
        reverse(result.begin(), result.end());

        return result;
    }
};
```

### Java Implementation

```java
import java.util.*;

class Solution {
    // Optimal Approach - HashMap + Min-Heap
    public List<String> topKFrequent(String[] words, int k) {
        // Step 1: Build frequency map
        Map<String, Integer> frequencyMap = new HashMap<>();
        for (String word : words) {
            frequencyMap.put(word, frequencyMap.getOrDefault(word, 0) + 1);
        }
        
        // Step 2: Create Min-Heap with custom comparator
        PriorityQueue<String> minHeap = new PriorityQueue<>(
            (word1, word2) -> {
                int freq1 = frequencyMap.get(word1);
                int freq2 = frequencyMap.get(word2);
                
                // Primary: Lower frequency at top (min-heap)
                if (freq1 != freq2) {
                    return freq1 - freq2;
                }
                // Secondary: Lexicographically larger word at top
                return word2.compareTo(word1);
            }
        );
        
        // Step 3: Process each unique word
        for (String word : frequencyMap.keySet()) {
            minHeap.offer(word);
            
            // Keep only k words in heap
            if (minHeap.size() > k) {
                minHeap.poll();  // Remove least deserving word
            }
        }
        
        // Step 4: Extract words from heap
        List<String> result = new ArrayList<>();
        while (!minHeap.isEmpty()) {
            result.add(minHeap.poll());
        }
        
        // Step 5: Reverse to get correct order
        Collections.reverse(result);
        
        return result;
    }
}
```

### Python Implementation

```python
from collections import Counter
import heapq

class Word:
    def __init__(self, word, freq):
        self.word = word
        self.freq = freq

    def __lt__(self, other):
        # Primary: Lower frequency has higher priority
        if self.freq != other.freq:
            return self.freq < other.freq

        # Secondary: Lexicographically larger word has higher priority
        return self.word > other.word


class Solution:
    # Optimal Approach - HashMap + Min-Heap
    def topKFrequent(self, words, k):
        # Step 1: Build frequency map
        frequencyMap = Counter(words)

        # Step 2: Create Min-Heap
        minHeap = []

        # Step 3: Process each unique word
        for word, freq in frequencyMap.items():
            heapq.heappush(minHeap, Word(word, freq))

            # Keep only k words in heap
            if len(minHeap) > k:
                heapq.heappop(minHeap)

        # Step 4: Extract words from heap
        result = []
        while minHeap:
            result.append(heapq.heappop(minHeap).word)

        # Step 5: Reverse to get correct order
        result.reverse()

        return result
```

### Complexity Analysis

#### Time Complexity: **O(N + U log k)**

- (Where **N** = total number of words, **U** = number of unique words, **k** = number of top frequent words required).
- First, we build the frequency map by traversing all **N** words, which takes **O(N)** time.
- Next, we process each of the **U** unique words using a Min-Heap of size **k**. Each insertion and possible removal from the heap costs **O(log k)**, so this step takes **O(U log k)** time.
- Finally, we extract **k** words from the heap and reverse the result, which together take **O(k log k)** time.
- Since **k ≤ U**, this does not change the overall complexity. So, the time complexity is **O(N + U log k)**.

### **Space Complexity: O(U + K)**

- We use a HashMap to store frequencies of **U** unique words, which takes **O(U)** space.
- The Min-Heap stores at most **k** words at any time, requiring **O(k)** space.
- The result list also stores **k** words (output space).
