## Problem Statement

In this problem, you are given an array of integers. Your task is to create a function that returns a new array with the elements of the original array in reverse order. The reversal should be performed without altering the original array; instead, you should produce a new one that contains the elements in reversed order.

## Example 1

> [!NOTE]
> **INFO**
> Example 1:
> 
> Input: Input: arr = [1, 2, 3, 4, 5]
> 
> Output: [5, 4, 3, 2, 1]
> 
> Explanation: The array is reversed to [5, 4, 3, 2, 1].

## Example 2

> [!NOTE]
> **INFO**
> Example 2:
> 
> Input: Input: arr = [10, 20, 30]
> 
> Output: [30, 20, 10]
> 
> Explanation: The array is reversed to [30, 20, 10].

## Intuition

The key requirement of this problem is that the original array should **not be modified**. Instead of reversing the array in place, we need to return a **new reversed version**. Java provides a convenient utility method, Collections.reverse(), which reverses a list **in place**. To ensure the original list remains unchanged, we first create a **copy** of the given list. Once the copy is created, we can safely reverse it without affecting the original data. This approach allows us to achieve the desired result with minimal code while maintaining clarity and correctness.

## Algorithm

**Step 1:** Create a new list reversed by passing the original list arr to the ArrayList constructor. This creates a shallow copy of the list, preserving the original array.

**Step 2:** Use Collections.reverse(reversed) to reverse the elements of the copied list.

**Step 3:** Return the reversed list as the final output.





## Time Complexity: O(n)

**Explanation: **

- Creating a copy of the list takes **O(n)** time.
- Reversing the list using Collections.reverse() also takes **O(n)** time.
- Since these operations are sequential, the overall time complexity remains **O(n)**.

## Space Complexity: O(n)

**Explanation: **

- A new list of size n is created to store the reversed elements.
- The original list remains unchanged, so additional space proportional to the input size is required.
