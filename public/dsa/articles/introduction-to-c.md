## Programming Language

A programming language is a computer language that is used by programmers (developers) to communicate with computers. It is a set of instructions written in any specific languages (C, C++, Java, Python) to perform a specific task.

## What is C++ ?

C++ is a high-level, general-purpose programming language **created** by Danish computer scientist **Bjarne Stroustrup**. It is known for its **flexibility**, **performance**, and **efficiency**.

## Why do we need it ?

We need **C++** because it supports the following features: 

- **Object-Oriented Programming.**
- **Control over system resources and memory.**
- **High performance with efficiency and speed**.

## **Uses of C++ in the Real World **

- **System / Software development. **
- **Game development.**
- **Real time systems.**

## Compilation Process

Overview of compilation: **Turning source code into executable code**.

## Steps in the compilation process:

- **Preprocessor: **Handles directives like ***#include*** and ***#define***.
- **Compiler: Translates code **into** assembly language. **
- **Assembler: Converts** **assembly** **code** into **machine** **code.**
- **Linker: Combines** multiple **object** **files** into a **single executable**, **using** **libraries** as needed.** **
