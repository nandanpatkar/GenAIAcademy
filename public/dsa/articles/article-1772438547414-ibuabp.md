# **Java Basic Input and Output**

In any programming language, you must know how to:

1. Display output
2. Take input

These are the foundation of interaction between your program and the user.

In Java, this is handled using:

- System.out.print()
- System.out.println()
- System.out.printf()
- Scanner class (for input)

# **Java Output**

Java sends output to the console (standard output) using:

Here:

- System → A built-in class
- out → A static object used for output
- print / println / printf → Methods used to display data

You don’t need to fully understand classes and static right now. That will be covered later.

# **Java Input**

So far, we displayed output. Now let’s take input from the user.

Java uses the Scanner class for input.

## **Step 1: Import Scanner**

> [!NOTE]
> **DEFAULT**
> import java.util.Scanner;

This allows your program to use the Scanner class.

## **Step 2: Create Scanner Object**

> [!NOTE]
> **DEFAULT**
> Scanner sc = new Scanner(System.in);

- System.in → standard input (keyboard)
- sc → object name

# **Why Input/Output Matters**

In coding interviews:

- Most problems require reading input
- Competitive programming relies heavily on input parsing
- Backend systems process user input continuously

Strong I/O understanding prevents:

- Input mismatch errors
- Type errors
- Unexpected crashes
