## Problem Statement

You are given a list of root words and a sentence. Your task is to transform the sentence such that each word in the sentence is replaced by the shortest root word from the list, if it matches as a prefix. A root word is a word that can serve as the beginning of a longer word.

For example, if the root word is "cat" and you have a word "cattle" in your sentence, "cat" is a prefix of "cattle". In this case, replace "cattle" with "cat" in the sentence.

Your function should return the modified sentence where each word has been replaced with the shortest possible root word.

### Example 1

> [!NOTE]
> **INFO**
> **Input:** roots = ["cat", "bat", "rat"], sentence = "the cattle was rattled by the battery"
> **Output:** "the cat was rat by the bat"
> **Explanation:** Each word in the sentence is checked to see if it starts with any root word.
> If it does, we replace it with the **shortest matching root**; otherwise, we keep the word unchanged.
> 
> - **cattle → cat**
> - **rattled → rat**
> - **battery → bat**
> 
> All other words remain the same.
> 
> **Final sentence:** **"the cat was rat by the bat"**

### Example 2

> **Output:** "a a b c"
> **Explanation:** Each word in the sentence starts with one of the given roots, so it gets replaced by that root.
> 
> - **aadsfasf → a**
> - **absbs → a**
> - **bbab → b**
> - **cadsfafs → c**
> 
> **Final sentence: "a a b c"**

### Example 3

> **Input:** roots = ["abc", "xyz"], sentence = "abcdefg xyzxyz yzz"

> - **yzz → no matching root (unchanged)**

### Constraints

- The length of the roots array is in the range **[1, 1000]**.
- The length of the sentence is in the range** [1, 10****4****]**.
- Each word in the roots and each word in the sentence consists only of **lowercase** letters.

## Real-Life Analogy

Imagine you are a **text message autocorrect system** trying to save typing effort. You have a dictionary of common abbreviated words (roots), and you want to help users type faster by automatically shortening words to their root forms when possible.

**Think of it like this, Your Root Dictionary:** ["tech", "comp", "info"]

**User types:** "The technology company provides information systems"

**Your Smart Shortening:**

1. "technology" → starts with "tech" → shorten to "tech"
2. "company" → starts with "comp" → shorten to "comp"
3. "information" → starts with "info" → shorten to "info"
4. "The", "provides", "systems" → no roots match → keep as is

**Result:** "The tech comp provides info systems"

This is exactly what the Replace Words problem does  it finds the **shortest meaningful prefix** (root) for each word and replaces the word with that root, making the sentence more concise!

## Brute-Force Approach

### Intuition

The most straightforward approach is to process each word in the sentence one by one. For each word, we check all root words in the dictionary to see if any of them is a prefix of the current word. Among all matching roots, we select the shortest one and replace the word with it. If no root matches, we keep the original word unchanged. So, the key steps we can follow are:

1. **Split the sentence** into individual words.
2. **For each word**, check all roots in the dictionary.
3. **Find all matching roots** (roots that are prefixes of the word).
4. **Select the shortest root** among matches.
5. **Replace the word** with the shortest root, or keep it if no match.
6. **Reconstruct the sentence** from modified words.

### Algorithm

1. Firstly, we first **split the sentence into words** using space as the delimiter **because** the sentence is space-separated and we need to process each word individually. Using **sentence.split(" ")** gives us an array of words that we can handle one by one.
2. Next, we **initialize a result list (or StringBuilder)** **because** we are building a new sentence where some words may be replaced while others remain unchanged. Storing words as we process them makes reconstruction easier and efficient.
3. Now, for **each word in the sentence**, we try to find the **shortest matching root** **because** the problem requires replacing a word with the smallest root that is its prefix.
4. 1. To do this, we:
  2. 1. Initialize a variable **shortestRoot = null** **because** we need a way to track the best root found so far for the current word.
  3. Then, we **check every root in the dictionary**:
  4. 1. We use **word.startsWith(root)** **because** a valid replacement must be a prefix of the word.
  5. If a root matches:
  6. 1. If no root has been selected yet, we store it.
    2. If a root is already stored, we compare lengths and keep the **shorter one** **because** the shortest root should be used for replacement.
5. After checking all roots:
6. 1. If a **shortestRoot** was found, we add it to the result **because** the word must be replaced.
  2. If no root matched, we add the original word **because** it should remain unchanged.
7. Finally, we **join all words with spaces** **because** the output must be a single sentence with space-separated words.
8. We return this reconstructed sentence as the final answer.

### C++ Implementation

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    // Brute Force Approach - Check all roots for each word
    string replaceWords(vector<string>& dictionary, string sentence) {
        // Step 1: Split sentence into words
        vector<string> words;
        string currentWord = "";

        for (char ch : sentence) {
            if (ch == ' ') {
                words.push_back(currentWord);
                currentWord = "";
            } else {
                currentWord += ch;
            }
        }
        words.push_back(currentWord);

        // Step 2: Initialize result list
        vector<string> result;

        // Step 3: Process each word
        for (string& word : words) {
            string shortestRoot = "";

            // Check each root in dictionary
            for (string& root : dictionary) {
                // Check if root is a prefix of word
                if (word.substr(0, root.length()) == root) {
                    // Update shortest root if this is shorter
                    if (shortestRoot.empty() || root.length() < shortestRoot.length()) {
                        shortestRoot = root;
                    }
                }
            }

            // Add shortest root or original word to result
            if (!shortestRoot.empty()) {
                result.push_back(shortestRoot);
            } else {
                result.push_back(word);
            }
        }

        // Step 4: Join words with spaces
        string answer = "";
        for (int i = 0; i < result.size(); i++) {
            answer += result[i];
            if (i != result.size() - 1) {
                answer += " ";
            }
        }

        return answer;
    }
};
```

### Complexity Analysis

#### Time Complexity: O(W × D × L)

- (where, '**W'** = number of words in the sentence**, 'D'** = number of roots in the dictionary** **and** 'L'** = average length of a root/word).
- We first split the sentence into words, which takes linear time in the length of the sentence.
- Then, for each of the **W** words, we check all **D** roots to find the shortest prefix match.
- Each prefix check using **startsWith()** compares characters one by one and takes **O(L)** time in the worst case. So, the total time complexity becomes: **O(W × D × L).**

#### Space Complexity: O(W + S)

- (where, **'W' **= number of words and **'S' ** = total length of the sentence).
- We store the split words and the result words, which together require space proportional to the number of words and the sentence length.
- A few extra variables are used, but they take constant space.
- So, the total auxiliary space complexity is: O(W + S)

## Optimal Approach

### Intuition

The brute-force approach checks **every root for every word**, which is wasteful since most roots don’t match most words. Using a **Trie (Prefix Tree)**, we can find the **shortest matching prefix** in **O(L)** time per word instead of **O(D × L)**. We **build the Trie once** from all roots (**O(D × L)**), then traverse it **character by character** for each word. We **stop at the first complete root** found, ensuring it’s the **shortest prefix**, and avoid unnecessary checks, following **only one path** per word.

### Algorithm

1. We start with building a Trie from the dictionary because we need efficient prefix searching, and Trie provides O(L) prefix lookups where L is the word length. Here, Trie Structure is like each node represents a character. And each node has, `children` map: character → child node and `isEndOfWord` boolean:  marks if a root ends here.  Next, the building process as for each root in dictionary, start from Trie root. For each character in root, If character path doesn't exist, create new node and move to child node. And in last, mark final node as end of word.
2. Split the sentence into words by using space as delimiter, same as brute force approach., like 'words = sentence.split(" ")'.
3. Now, For each word, search for shortest root in Trie because Trie allows us to find the shortest matching prefix efficiently by stopping at the first complete root encountered. Search process foreach word:
4. 1. Start from Trie root:
  2. 1. **'currentNode = trieRoot'**
    2. **'StringBuilder prefix = new StringBuilder()'.**
  3. Traverse word character by character, For each character **'c' **in word:
  4. 1. **Check if path exists:-**
    2. 1. If **'currentNode'** has child for character  **'c' :**
      2. 1. Append **'c' ** to **'perfix'. **
        2. **Move to child: 'currentNode = currentNode.children.get(c)'**.
    3. **Check if we found a complete root:-**
    4. 1. If **'currentNode.isEndOfWord == true':**
      2. 1. **Return** **prefix** immediately  (this is the shortest root).
        2. Early termination saves time. Else (no path for this character):
        3. 1. **Break** the loop (no root matches).
          2. **Return** original word.
    5. ** If loop completes without finding root:**
    6. 1. **Return** original word (no matching prefix found).
5. Next we collect replacement words into result list because we need to build the transformed sentence as add each returned word (root or original) to result list.
6. Further, we join words with spaces to create the final sentence. For this use **'String.join(" ",resultList)'**.
7. At last, we return the transformed sentence as the final result.

### C++ Implementation

```cpp
#include <vector>
#include <string>
#include <unordered_map>
using namespace std;

class Solution {
    // Trie Node class
    struct TrieNode {
        unordered_map<char, TrieNode*> children;
        bool isEndOfWord;

        TrieNode() {
            isEndOfWord = false;
        }
    };

public:
    // Optimal Approach - Using Trie
    string replaceWords(vector<string>& dictionary, string sentence) {
        // Step 1: Build Trie from dictionary
        TrieNode* root = new TrieNode();
        for (string& word : dictionary) {
            insertIntoTrie(root, word);
        }

        // Step 2: Split sentence into words
        vector<string> words;
        string currentWord;

        for (char ch : sentence) {
            if (ch == ' ') {
                words.push_back(currentWord);
                currentWord.clear();
            } else {
                currentWord += ch;
            }
        }
        words.push_back(currentWord);

        vector<string> result;

        // Step 3: For each word, search for shortest root in Trie
        for (string& word : words) {
            result.push_back(searchShortestRoot(root, word));
        }

        // Step 4: Join words with spaces
        string answer;
        for (int i = 0; i < result.size(); i++) {
            answer += result[i];
            if (i != result.size() - 1) {
                answer += " ";
            }
        }

        return answer;
    }

private:
    // Helper: Insert word into Trie
    void insertIntoTrie(TrieNode* root, string& word) {
        TrieNode* current = root;

        for (char ch : word) {
            if (current->children.find(ch) == current->children.end()) {
                current->children[ch] = new TrieNode();
            }
            current = current->children[ch];
        }

        current->isEndOfWord = true;
    }

    // Helper: Search for shortest matching root
    string searchShortestRoot(TrieNode* root, string& word) {
        TrieNode* current = root;
        string prefix;

        for (char ch : word) {
            // If no path exists, no root matches
            if (current->children.find(ch) == current->children.end()) {
                break;
            }

            // Move to next character
            prefix += ch;
            current = current->children[ch];

            // If we found a complete root, return immediately
            if (current->isEndOfWord) {
                return prefix;
            }
        }

        // No matching root found, return original word
        return word;
    }
};
```

### Java Implementation

```java
import java.util.*;

class Solution {
    // Trie Node class
    class TrieNode {
        Map<Character, TrieNode> children;
        boolean isEndOfWord;
        
        TrieNode() {
            children = new HashMap<>();
            isEndOfWord = false;
        }
    }
    
    // Optimal Approach - Using Trie
    public String replaceWords(List<String> dictionary, String sentence) {
        // Step 1: Build Trie from dictionary
        TrieNode root = new TrieNode();
        for (String word : dictionary) {
            insertIntoTrie(root, word);
        }
        
        // Step 2: Split sentence into words
        String[] words = sentence.split(" ");
        List<String> result = new ArrayList<>();
        
        // Step 3: For each word, search for shortest root in Trie
        for (String word : words) {
            String replacement = searchShortestRoot(root, word);
            result.add(replacement);
        }
        
        // Step 4: Join words with spaces
        return String.join(" ", result);
    }
    
    // Helper: Insert word into Trie
    private void insertIntoTrie(TrieNode root, String word) {
        TrieNode current = root;
        for (char c : word.toCharArray()) {
            current.children.putIfAbsent(c, new TrieNode());
            current = current.children.get(c);
        }
        current.isEndOfWord = true;
    }
    
    // Helper: Search for shortest matching root
    private String searchShortestRoot(TrieNode root, String word) {
        TrieNode current = root;
        StringBuilder prefix = new StringBuilder();
        
        for (char c : word.toCharArray()) {
            // If no path exists, no root matches
            if (!current.children.containsKey(c)) {
                break;
            }
            
            // Move to next character
            prefix.append(c);
            current = current.children.get(c);
            
            // If we found a complete root, return immediately
            if (current.isEndOfWord) {
                return prefix.toString();
            }
        }
        
        // No matching root found, return original word
        return word;
    }
}
```

```python
    def __init__(self):
        self.children = {}
        self.isEndOfWord = False
```

### Complexity Analysis

#### Time Complexity: O(D × L + W × L)

- (Where **D** = number of roots in dictionary, **W** = number of words in sentence, **L** = average length of words/roots).
- First, we build the Trie by inserting all **D** roots.
- Each insertion takes **O(L)** time, so Trie construction costs **O(D × L)**.
- Next, we process the sentence as for each of the **W** words, we traverse the Trie character by character until we either:
- - find a valid root, or
  - fail to match further characters.
- In the worst case, this traversal takes **O(L)** time per word, giving **O(W × L)** for all words.
- So, the total time complexity is: **O(D × L + W × L) = O((D + W) × L)**

### **Space Complexity: O(D × L)**

- The Trie stores all characters of the dictionary roots.
- In the worst case, each root contributes `L` nodes, resulting in **O(D × L)** space.
- Additional space is used for:
- - the split words array and result list → **O(W).**
  - temporary variables → **O(1).**
- Since Trie storage dominates, the overall auxiliary space complexity is: **O(D × L)**.
