## Problem Statement

Given two arrays, ***arr1*** and ***arr2***, your task is to determine if ***arr2*** is a subset of ***arr1***. An array ***arr2*** is considered a subset of ***arr1*** if every element of ***arr2*** is also present in ***arr1***, with at least the same frequency. The function should return "Yes" if ***arr2*** is a subset of ***arr1***, and "No" otherwise.

### Example 1

> [!NOTE]
> **INFO**
> **Input:** arr1 = [1, 2, 3, 4, 5], arr2 = [2, 3, 4]
> **Output:** Yes
> **Explanation:** We verify each element of **arr2** against **arr1 **to ensure it is present. All elements of **arr2** which is **2**, **3**, and **4**, are found in **arr1**. Since no element is missing, the result is **Yes**.

### Example 2

> [!NOTE]
> **INFO**
> **Input:** arr1 = [10, 5, 2, 23, 19], arr2 = [19, 5, 3]
> **Output:** No
> **Explanation:** We check whether every element of **arr2** exists in **arr1**. While **19** and **5** are present, the element** 3** is missing from **arr1**. Since not all elements of **arr2** are found, the output is **No**.

### Example 3

> [!NOTE]
> **INFO**
> **Input:** arr1 = [1, 2, 3, 4, 5, 6, 7], arr2 = [1, 7, 6, 3]
> **Output: **Yes
> **Explanation:** We check each element of **arr2** to see if it exists in **arr1**. All elements which is **1, 7, 6, **and** 3** are present in **arr1.** Since every element is found, the output is **Yes**.

### Constraints

- **1 <= n, m <= 10****4**
- **1** <= **arr1[i]**, **arr2[j]** <=** 10****6**

## Brute-Force Approach

### Intuition

The most straightforward approach is to check each element of **arr2** and verify if it exists in **arr1** with sufficient frequency. For each element in **arr2**, we count how many times it appears in both arrays. If any element in **arr2** appears more times than in **arr1**, then **arr2** cannot be a subset.

**Key steps:**

1. For each element in **arr2.**
2. Count its frequency in both **arr1** and **arr2.**
3. If frequency in **arr2** > frequency in **arr1**, return "No".
4. If all elements satisfy the condition, return "Yes".

### Algorithm

1. We take an** array lengths** which is **m **and **n **for **arr1 **and **arr2** respectively, because we need these for loop bounds and basic validation.
2. Next we check the early termination as if **arr2 **is longer than **arr1 **it means n > m. So, we immediately return **NO **because a larger array cannot be a subset of a smaller array, there are not enough elements to match.
3. Now, we check for each element in **arr2, **we need to verify it exists in **arr1** with sufficient frequency because every element of **arr2** must be present in **arr1** at least as many times as it appears in **arr2**. **Process for each unique element in arr2.**
4. Then we** count frequency in arr2** by iterating through **arr2** and counting how many times the current element appears because we need to know the required frequency.

   **freq2 = 0**
**   ****for each element in arr2:**
**       ****if element equals current element:**
**         ****  ****freq2++**

1. **Further **check for the** arr1 **as** **we** count frequency in arr1** by iterating through **arr1** and counting how many times the same element appears because we need to know the **available** **frequency**.

**   freq1 = 0**
**   for each element in arr1:**
**       if element equals current element:**
**           freq1++**

1. After this,** **we **compare the frequencies as** **if freq2 > freq1,** this means **arr2** needs more occurrences of this element than **arr1** has available, so we return **"No"** immediately because the subset condition is violated.
2. **We track processed elements** to avoid checking the same element multiple times because once we have verified an element's frequency, we don't need to check it again when we encounter it later in arr2.
3. - We use a simple approach: **mark elements as checked.**
  - **Or skip if **we have** already processed this value.**
4. **If all elements pass the frequency check**, **return** **"Yes"** because every element in **arr2** exists in **arr1** with sufficient frequency, satisfying the subset condition.

### C++ Implementation

```cpp
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    // Brute Force Approach - Check frequency of each element
    string isSubset(vector<int>& arr1, vector<int>& arr2) {
        int m = arr1.size();
        int n = arr2.size();

        // Step 1: Early termination - subset can't be larger
        if (n > m) {
            return "No";
        }

        // Step 2: Track processed elements to avoid duplicates
        vector<bool> processed(n, false);

        // Step 3: Check each element in arr2
        for (int i = 0; i < n; i++) {

            // Skip if already processed
            if (processed[i]) {
                continue;
            }

            int currentElement = arr2[i];

            // Step 4: Count frequency in arr2
            int freq2 = 0;
            for (int j = 0; j < n; j++) {
                if (arr2[j] == currentElement) {
                    freq2++;
                    processed[j] = true;
                }
            }

            // Step 5: Count frequency in arr1
            int freq1 = 0;
            for (int j = 0; j < m; j++) {
                if (arr1[j] == currentElement) {
                    freq1++;
                }
            }

            // Step 6: Compare frequencies
            if (freq2 > freq1) {
                return "No";
            }
        }

        // Step 7: All elements verified
        return "Yes";
    }
};
```

        n = len(arr2)

                    freq2 += 1
                    processed[j] = True

            # Step 5: Count frequency in arr1
            freq1 = 0
            for j in range(m):
                if arr1[j] == currentElement:
                    freq1 += 1

            # Step 6: Compare frequencies
            if freq2 > freq1:
                return "No"

        # Step 7: All elements verified
        return "Yes"

### Complexity Analysis

#### Time Complexity: O(n × (n + m))

- (where **n **=** length of arr2** and** m **=** length of arr1**).
- The algorithm iterates through **arr2** to process each element. In the worst case, all **n** elements are unique, so the outer loop runs **n **times.
- For every unique element in **arr2**, we scan the **entire arr2** to count its frequency, which takes **O(n)** time.
- We also scan the **entire arr1** to count the frequency of the same element, which takes **O(m)** time.
- These two scans are required for every unique element to ensure frequency matching.
- Since this combined work **O(n + m)** happens up to `n` times, the total time becomes: **n × (n + m) = O(n × (n + m))**

#### Space Complexity: O(n)

- The only auxiliary structure used is the **processed** boolean array of size **n**, plus constant-sized variables.
- So the auxiliary space remains **O(n)**.



## Optimal Approach

### Intuition

The brute-force method is inefficient because it repeatedly recalculates frequencies for the same elements. A better approach is to use a **HashMap (frequency map)** to count each element only once. First, traverse **arr1** and store the frequency of every element in the map. Then iterate through **arr2** and for each element, check whether it exists in the map; if it does not, **arr2** cannot be a subset and we return “No”. If it exists, decrement its count, and if the count ever becomes negative, it means **arr2** requires more occurrences than **arr1** provides, so return “No”. If all elements of **arr2 **are validated successfully, return “Yes”. This approach is more efficient because it builds the frequency map in **O(m)** time, verifies elements in **O(n)** time, avoids repeated counting, and uses constant-time lookups for each check.

### Algorithm

1. **Firstly, we compute the lengths** of both arrays. Let **m** be the length of the first array and **n** be the length of the second array.
2. **Then, we perform an early check.** If **n** is greater than **m**, we directly return **"No"** because a larger array cannot be a subset of a smaller one, as there are not enough elements to match.
3. **Next, we create a frequency map** to store the count of each element present in the first array. This is required to track how many times each element is available, and using a map allows fast lookup and updates.
4. **After that, we traverse the first array** and build the frequency map. For each element:
5. - If the element is already present in the map, we increase its count.
  - Otherwise, we add the element to the map with a count of one.
This step ensures that we know the exact frequency of every element in the first array.
6. **Then, we iterate through the second array** to verify whether it can be formed from the elements of the first array.
7. **For each element of the second array, we first check** whether it exists in the frequency map:
8. - If it does not exist, we immediately return **"No"** because the required element is not present in the first array at all.
9. **If the element exists, we check its frequency** in the map:
10. - If the frequency is zero or negative, it means all occurrences of that element have already been used, so we return **"No"**.
  - If the frequency is positive, we decrease the count by one to indicate that one occurrence of the element has been used.
11. **Finally, after all elements of the second array are processed successfully,** we return **"Yes"** because every element exists in the first array and appears with sufficient frequency, confirming that the second array is a valid subset of the first array.

### C++ Implementation

```cpp
#include <vector>
#include <unordered_map>
#include <string>
using namespace std;

class Solution {
public:
    // Optimal Approach - Using HashMap
    string isSubset(vector<int>& arr1, vector<int>& arr2) {
        int m = arr1.size();
        int n = arr2.size();

        // Step 1: Early termination check
        if (n > m) {
            return "No";
        }

        // Step 2: Create frequency map
        unordered_map<int, int> freqMap;

        // Step 3: Build frequency map from arr1
        for (int i = 0; i < m; i++) {
            freqMap[arr1[i]]++;
        }

        // Step 4: Verify each element of arr2
        for (int i = 0; i < n; i++) {
            int element = arr2[i];

            // Step 5: Check if element exists
            if (freqMap.find(element) == freqMap.end()) {
                return "No";
            }

            // Step 6: Check and update frequency
            int count = freqMap[element];

            if (count <= 0) {
                return "No";
            }

            // Decrement count (use one occurrence)
            freqMap[element]--;
        }

        // Step 7: All elements verified successfully
        return "Yes";
    }
};
```

### Java Implementation

```java
import java.util.*;

class Solution {
    // Optimal Approach - Using HashMap
    public String isSubset(int[] arr1, int[] arr2) {
        int m = arr1.length;
        int n = arr2.length;

        // Step 1: Early termination check
        if (n > m) {
            return "No";
        }

        // Step 2: Create frequency map
        Map<Integer, Integer> freqMap = new HashMap<>();

        // Step 3: Build frequency map from arr1
        for (int i = 0; i < m; i++) {
            freqMap.put(arr1[i], freqMap.getOrDefault(arr1[i], 0) + 1);
        }

        // Step 4: Verify each element of arr2
        for (int i = 0; i < n; i++) {
            int element = arr2[i];

            // Step 5: Check if element exists
            if (!freqMap.containsKey(element)) {
                return "No";
            }

            // Step 6: Check and update frequency
            int count = freqMap.get(element);

            if (count <= 0) {
                return "No";
            }

            // Decrement count (use one occurrence)
            freqMap.put(element, count - 1);
        }

        // Step 7: All elements verified successfully
        return "Yes";
    }
}
```

### Complexity Analysis

#### Time Complexity: O(m+n)

- (where **m **=** length of arr1** and **n **= **length of arr2**).
- The algorithm first scans **arr1 once** to build a frequency map, which takes **O(m)** time.
- Each insertion and update in the HashMap during this scan happens in **O(1)** average time.
- Next, the algorithm scans **arr2 once** to verify frequencies, which takes **O(n)** time.
- HashMap operations like **containsKey**, **get**, and **put** during this phase also run in **O(1)** average time.
- Since both arrays are traversed only once and no nested loops are involved, the total time is the sum of both passes.
- **Overall Time Complexity:** O(m)+O(n)=O(m+n).

### **Space Complexity: **O(m)

- A HashMap is used to store the frequency of elements from **arr1**, which can store up to **m** entries in the worst case.
- Apart from the HashMap, only a few constant-sized variables are used.
- No additional data structures grow with **arr2**.
- **Overall Space Complexity:** O(m).
