## Variable

A **variable** in C++ is a named storage location in memory used to store data.
It acts like a **container that holds information**, and this information can be changed or used during the execution of a program.

For example, a variable can store numbers, characters, or other types of data that a program needs to process.

## **Key Points About Variables**

- A variable **stores data in the computer's memory**.
- Each variable has a **name (identifier)** used to access its stored value.
- The value stored in a variable **can change during program execution**.
- Before using a variable, it must be **declared with a specific data type**.

## **Working with Variables**

**To use a variable in C++, you generally follow these steps:**

1. **Declaration** – Specify the variable's data type and name.
2. **Definition** – Allocate memory for the variable.
3. **Initialization** – Assign an initial value to the variable.



**Example: int age = 25;**

Here:

- **int → data type**
- **age → variable name**
- **25 → value stored in the variable**

## **Data Types in C++**

C++ provides different **data types** to store different kinds of data. Each data type has a specific purpose and occupies a certain amount of memory.



### **1. Primitive Data Types**

These are the **basic built-in data types** provided by C++.

**Examples:**

- int – stores integers
- float – stores decimal numbers
- double – stores large decimal numbers
- char – stores a single character
- bool – stores true or false values

### **2. Derived Data Types**

These data types are **derived from primitive data types** and provide more complex ways to store data.

**Examples:**

- Arrays
- Pointers
- References
- Functions

### **3. User-Defined Data Types**

These are **custom data types created by the programmer** to represent more complex data structures.

**Examples:**

- struct (Structure)
- union
- enum
- class

**Important Note**

- The **size of data types may vary depending on the system architecture** (for example, 32-bit or 64-bit systems).
- This means the memory used by some data types can differ across different platforms.
